# 🚀 Checklist de Inicialização de Projeto

Siga este passo a passo rigorosamente antes de escrever a primeira linha de código.

## Fase 0: Setup
- [ ] 1. Copiar este template para a nova pasta do projeto.
- [ ] 2. Renomear a pasta para o nome do projeto.
- [ ] 3. Abrir a pasta na IDE (Antigravity / VSCode).
- [ ] 4. Inicializar o repositório: `git init`.

## Fase 1: Negócios e Escopo
- [ ] 5. Ativar a IA com a skill `project-planner` ou `product-manager`.
- [ ] 6. Gerar o Plano de Projeto e salvar em `docs/01_PROJECT_PLAN.md`.
- [ ] 7. Ativar a IA com a skill `product-owner`.
- [ ] 8. Gerar o PRD (Product Requirements Document) e salvar em `docs/02_PRD.md`.

## Fase 2: Engenharia e Arquitetura
- [ ] 9. Ativar a IA com os **Prompts de Elite (Escalabilidade + Segurança)**.
- [ ] 10. Fornecer o PRD para a IA e pedir a Especificação Técnica.
- [ ] 11. Salvar a arquitetura gerada em `docs/03_SPECS.md`.
- [ ] 12. Realizar a Modelagem de Ameaças e salvar em `docs/04_THREAT_MODEL.md`.

## Fase 3: Infraestrutura e Código
- [ ] 13. Criar o `docker-compose.yml` para dependências locais (Banco, Redis).
- [ ] 14. Configurar linters e formatadores (ESLint, Prettier, Ruff, etc).
- [ ] 15. Iniciar o desenvolvimento no diretório `/src` utilizando o **Prompt de Backend**.
- [ ] 16. Criar os testes no diretório `/tests` utilizando o **Prompt de SRE/QA**.
