# 🚀 Boilerplate de Engenharia de Software (Template)

Este é um repositório de **Template (Molde)**. Ele contém a estrutura base, os prompts de Inteligência Artificial de nível Sênior e o fluxo de documentação necessários para iniciar projetos de software escaláveis, seguros e profissionais.

---

## 🛠️ Como criar um novo projeto a partir deste template

**NÃO clone este repositório diretamente.** Siga os passos abaixo para gerar um novo projeto limpo:

### Passo 1: Gerar no GitHub
1. No canto superior direito desta página, clique no botão verde **"Use this template"** (Usar este modelo).
2. Selecione **"Create a new repository"**.
3. Dê um nome para o seu novo projeto (ex: `meu-novo-app`).
4. Clique em **"Create repository"**.

### Passo 2: Configurar Localmente
Após o GitHub gerar o seu novo repositório, abra o terminal no seu computador e faça o clone do **seu novo projeto**:

```bash
# Substitua pela URL do seu novo repositório
git clone https://github.com/SEU_USUARIO/meu-novo-app.git

# Entre na pasta
cd meu-novo-app
```

---

## 📂 Estrutura do Projeto

Este template já vem configurado com a arquitetura de pastas ideal para o desenvolvimento:

* **`.prompts/`**: Contém os Agentes/Prompts de IA de nível Elite (Segurança, Escalabilidade, SRE, Backend). Use-os na sua IDE para guiar o desenvolvimento.
* **`docs/`**: O coração do planejamento. Contém os templates vazios para o Plano de Projeto, PRD, SPECs Técnicas e Modelagem de Ameaças.
* **`src/`**: Onde o código-fonte da aplicação irá nascer.
* **`tests/`**: Onde os testes automatizados (Unitários, E2E, Carga) irão morar.

---

## 🏁 Primeiros Passos (Obrigatório)

Assim que você clonar o seu novo projeto para a máquina, **NÃO comece a programar**. 

Abra o arquivo **`CHECKLIST_INICIAL.md`** na raiz do projeto e siga o passo a passo rigorosamente. A engenharia começa na documentação (`/docs`), garantindo que a Inteligência Artificial tenha 100% de contexto antes de escrever a primeira linha de código.
